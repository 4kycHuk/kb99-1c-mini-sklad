# Мини-Склад

Учебный проект на платформе 1С:Предприятие 8.3.

## Назначение

Конфигурация предназначена для учёта товаров на складе.

## Реализованные объекты

- Справочник «Товары»
- Справочник «Контрагенты»
- Документ «Поступление товаров»
- Документ «Реализация товаров»
- Регистр накопления «Остатки товаров»
- Отчёт «Остатки товаров»
- Контроль достаточности товарных остатков при реализации

## Технологии

- 1С:Предприятие 8.3
- Git
- GitHub
